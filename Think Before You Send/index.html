The 30-second check

Before you send, check four things.

Good emails aren't about sounding overly formal. They're about helping the reader understand what is needed.

01 · ContextDoes the reader know why you're writing?
02 · ActionIs the required next step clear?
03 · TimelineHave you stated when it's needed?
04 · ToneDoes it sound professional and respectful?
Remember: The goal is clarity, not longer emails.
Spot the problem

This email is short. But is it clear?

Example email
Subject: Pending
To: Team
Hi,

This is still pending. Please do it ASAP as we already discussed this.

Thanks.
ContextWhich task is pending?
ActionWhat exactly should the reader do?
TimelineASAP doesn't specify a deadline.
ToneThe message may sound abrupt.
Make it actionable

Same message. Better communication.

Before

"This is still pending. Please do it ASAP as we already discussed this."

After

"Hi team, the Q3 tracker update is still pending. Please complete the remaining entries and share the updated file by 3:00 PM today. Thanks."

What changed? The improved version provides context, a specific action, a clear timeline and a neutral professional tone.
